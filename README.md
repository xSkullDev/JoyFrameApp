# JoyFrame Photobooth (demo)

Proyek statis demo photobooth. Cara pakai:
- Buka index.html di browser.
- Ganti gambar di assets/images dengan foto milik Anda.
- Sesuaikan teks dan warna di assets/css/styles.css.

Catatan: Ini dibuat sebagai halaman original yang terinspirasi; jangan salin konten berhak cipta dari pihak lain.
